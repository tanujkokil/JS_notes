# Object.assign()

- Object.assign() copies properties from one or more source objects into a target object.
- Copies own enumerable properties
- Performs a shallow copy
- Does not create a new prototype

# Object.create()

- Object.create() creates a new object with a specified prototype.
- Sets the prototype of the new object
- Does not copy properties
- Used for inheritance
- No mutation of existing objects
