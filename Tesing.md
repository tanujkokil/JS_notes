 # SnapShot testing
  > where you capture the rendered output of a component and compare it in future runs to detect unintended changes.

  > How it works

  - Render a component<br></br>
  - Generate a snapshot (JSON / tree structure)<br></br>
  - Save it (first time)<br></br>
  - Next time → compare new output with saved snapshot<br></br>

  > why we need

  - Detects unexpected UI changes<br></br>
  - Fast to write (less boilerplate)<br></br>
  - Good for regression testing<br></br>
