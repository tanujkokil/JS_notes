# let  

- Using let wa can recreate and redecleare the variable without using let keyword
- It is block scope
- let is hoisted.with refrence error

# const

- Using const we can not recreate and redecleare the variable
- It is block scope
- let is hoisted.with refrence error

# var

- Using var we can recreate the variable and redeclare using var.
- It is a function scope .
- var is hosted with undefined.
