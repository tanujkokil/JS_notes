# map()

- Transforms each item and returns a new array
- Returns a new array with transformed values
- Used to transform data without mutating original
- Chainable (returns array)
- Doesn’t change original array

# forEach()

- Executes a function for each item
- Always returns undefined
- Usually used for side effects (e.g., logging, updating DOM)
- Not chainable (because it returns undefined)
- Doesn’t change original array unless mutated manually
